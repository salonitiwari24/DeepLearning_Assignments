# Deep Learning Assignments

This repository contains the practical implementations completed as part of the
Deep Learning course for the academic year 2026–27.

The assignments cover fundamental neural networks, backpropagation, recurrent
neural networks, convolutional neural networks, transfer learning, transformers,
and deep-learning applications for audio.
